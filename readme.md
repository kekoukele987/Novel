## 🧩 核心设定速览

### 🌐 灵视等级

| 等级 | 能力 | 占比 |
|:----:|------|:----:|
| 凡眼 | 未觉醒 | 99.9% |
| 开眼 | 模糊感知灵质波动 | 0.08% |
| 明瞳 | 清晰看到灵体，基础操控 | 0.015% |
| 慧眼 | 看穿幻象，灵质具象化战斗 | 0.004% |
| 天瞳 | 预知片段，读灵，领域展开 | 0.0009% |
| 归无 | 与灵质完全同频，触及世界真相 | **仅一人** |

### ⚔️ 三大势力

```
归墟会 ── 远古守护者，传承三千年，隐于幕后操控历史
  ↑↓
灵调局 ── 官方秘密机构，维稳第一，不择手段掩盖真相
  ↓↑
 暗界  ── 民间觉醒者联盟，松散自由，追求公开真相
```

### 👥 核心角色

- **陆渊**（主角）—— 24岁，归无级觉醒者，母亲被灭口，追查真相中
- **苏挽晴**（灵调局组长）—— 27岁，慧眼中阶，身负父母被灵调局秘密实验杀害的隐情
- **老鬼 / 魏九**（情报贩子）—— 前归墟会执事，断指瞎眼，背负三十年前小队全灭的秘密
- **谢暮桥**（归墟会执事长 / 天一集团总裁）—— 39岁，唯一穿越过归墟之门的男人，情感被烧毁的理性疯子
